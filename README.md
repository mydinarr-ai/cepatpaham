# CepatPaham

Hitung cepat. Paham konsep.

Aplikasi web latihan matematika SMP kelas VII sampai SMA/SMK kelas XII: materi sekolah sesuai kelas dan trik hitung cepat. Berjalan di browser HP, bisa dipasang di layar utama, dan jalan tanpa internet setelah dibuka sekali.

- Pengembangan: lihat `PANDUAN-PENGEMBANGAN.md`
- Uji otomatis: `node uji.js`
- Coba lokal: `node serve.js`, lalu buka http://localhost:5173
